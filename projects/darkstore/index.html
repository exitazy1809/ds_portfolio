Darkstore

Прогнозирование недельных продаж

CatBoost · PostgreSQL · Airflow · S3

О проекте

Production-пайплайн для автоматизации прогнозирования недельных продаж магазинов и отделов.

Модель используется для планирования продаж, оценки нагрузки и поддержки бизнес-решений.

Результат

CatBoostRegressor

Градиентный бустинг для прогнозирования weekly_sales.

Time Series Features

Лаги, rolling statistics и временные признаки для моделирования динамики продаж.

Batch Inference

Регулярный запуск прогнозирования через Apache Airflow.

Дополнительно выполняется обработка аномалий, заполнение пропусков и подготовка категориальных признаков.

Production Pipeline

1. PostgreSQL

Загружаются исторические продажи, плановые даты, информация о магазинах и внешние признаки.

2. Preprocessing

Генерируются временные признаки, лаги и rolling statistics.

3. S3

Обученная модель хранится в Yandex Object Storage.

4. Batch inference

Airflow загружает модель и выполняет прогнозирование для планового периода.

5. PostgreSQL

Результаты сохраняются в таблицу predictions.

Airflow DAG

Основной DAG:

sales_prediction_batch_inference

  1. load_data
  2. preprocess_features
  3. load_model
  4. run_inference
  5. save_predictions

DAG запускается по расписанию и выполняет полный batch inference pipeline.

Архитектура

PostgreSQL → Feature Engineering → CatBoost → S3 → Airflow → Predictions → PostgreSQL
