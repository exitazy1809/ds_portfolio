Hotel Bookings

Прогнозирование отмен бронирований

CatBoost · XGBoost · LightGBM · NLP · SHAP · Optuna

О проекте

ML-модель для прогнозирования вероятности отмены бронирования с использованием характеристик брони и текстовой информации из отзывов клиентов.

Основная бизнес-цель — заранее выявлять рискованные бронирования и оценивать потенциальный revenue uplift от целевых интервенций.

Данные

Bookings 30 733
Features 526
TF-IDF 500

Около 27% бронирований содержали доступный текстовый отзыв. Текстовые данные были преобразованы в TF-IDF представление с ограничением словаря до 500 признаков.

Feature Engineering

Были созданы бизнес-интерпретируемые признаки:

  • total_guests — общее количество гостей;
  • stay_nights — продолжительность проживания;
  • price_per_night — стоимость одной ночи;
  • is_last_minute — бронирование менее чем за 3 дня;
  • has_special_requests — наличие специальных запросов.

Дополнительно из текстов отзывов были получены 500 TF-IDF признаков.

Моделирование

CatBoost

Градиентный бустинг с поддержкой категориальных признаков.

LightGBM

Альтернативная модель для сравнения качества классификации.

XGBoost

Дополнительный baseline для сравнения алгоритмов.

Гиперпараметры оптимизировались с использованием Optuna. Для итоговой модели использовалась схема разделения данных на train, calibration и test выборки.

Вероятности модели дополнительно калибровались, после чего подбирался оптимальный порог классификации по бизнес-метрике Incremental Revenue.

Итоговая модель

Model CatBoost
Iterations 480
Threshold 0.533

Финальная модель: CatBoost + Isotonic Calibration.

  • depth = 4
  • learning_rate ≈ 0.196
  • iterations = 480
  • l2_leaf_reg ≈ 7.25
  • optimal threshold = 0.533

Бизнес-результат

Calibration 215.4 млн ₽
Test 214.5 млн ₽
Metric IR

Значения Incremental Revenue на calibration и test выборках находятся на близком уровне, что является хорошим признаком устойчивости выбранного решения.

Интерпретация модели

SHAP-анализ показал значительный вклад текстовых TF-IDF признаков в прогнозирование отмен.

Среди табличных признаков наиболее заметны продолжительность проживания, количество гостей, стоимость проживания и наличие специальных запросов.

Сочетание классических табличных признаков и NLP позволяет учитывать как характеристики бронирования, так и текстовую историю взаимодействия клиента.
