Цель проекта:

Разработать и оценить модель машинного обучения для предсказания возрастной категории пользователя на основе его поведенческих и агрегированных данных, обеспечив высокое и устойчивое качество классификации по всем классам с использованием метрики F1_macro.

Вывод

- Проведена предобработка данных: обработка пропусков, масштабирование и кодирование категориальных признаков.
- Сравнены DummyClassifier, Logistic Regression и SVM с разными ядрами.
- С помощью Feature Engineering и RFE улучшены и отобраны наиболее информативные признаки.
- Лучшая модель — SVM с полиномиальным ядром + FE + RFE.
- F1_macro на кросс-валидации — ~0.89, на тестовой выборке — ~0.87.
- Модель достигла требуемого качества (F1_macro ≥ 0.75) и была сохранена в age_category_model.pkl.

Итог: модель показывает стабильное и сбалансированное качество классификации возрастных категорий и готова к дальнейшему использованию.

Требование (F1 ≥ 0.75) выполнено.

Модель можно рекомендовать к внедрению, так как она показывает высокое и сбалансированное качество по всем классам, включая редкие.
